容大进销存系统 - 主机端局域网配置说明

适用对象：作为服务器的电脑，也就是运行“容大进销存系统”的电脑。

操作步骤：
1. 双击“主机端-一键开启局域网访问.bat”。
2. Windows 弹出管理员权限提示时，点击“是”。
3. 工具会自动查找安装版或绿色版 IVS.exe，并配置防火墙、启动系统。
4. 工具窗口中会显示其他电脑应使用的局域网地址，例如：
   http://192.168.1.101:8090/
5. 将该地址填写到局域网客户端登录工具中。

程序查找顺序：
- 当前 Windows 用户的安装目录；
- 其他 Windows 用户的安装目录；
- Program Files 下的安装目录；
- 主机工具同目录、上级目录及邻近的绿色版目录。

如果提示找不到 IVS.exe：
1. 确认已运行“容大进销存系统.exe”完成安装；或
2. 将“容大进销存-主机端工具”文件夹放到绿色版 IVS.exe 所在目录；或
3. 在启动命令前设置环境变量 IVS_HOME 指向 IVS.exe 所在文件夹。

注意事项：
- 主机必须保持开机，进销存系统必须保持运行。
- 主机网络应设置为“专用网络”，不要设置为“公用网络”。
- 如果电脑使用 Wi-Fi，确保没有连接到来宾网络。
- 不建议在主机上同时运行其他占用 8090 端口的程序。
- 更换网络或 IP 地址变化后，重新运行本工具，并将新地址发给客户端。
- 局域网客户端必须使用 v1.9.30 或更新版本。

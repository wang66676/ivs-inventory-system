容大进销存系统 - 局域网客户端使用说明

一、使用前确认
1. 主机电脑已经开机。
2. 主机电脑已经打开“容大进销存系统”。
3. 主机电脑已运行“主机端-一键开启局域网访问”。
4. 当前电脑与主机电脑连接同一个 Wi-Fi 或同一个局域网。

二、客户端使用方法
1. 必须先解压整个 ZIP 文件，不能直接在压缩包里双击运行。
2. 双击“容大进销存-局域网登录.exe”。
   如果 Windows 提示“已保护你的电脑”，点击“更多信息”，再点击“仍要运行”。
3. 程序会自动检测主机是否在线。
4. 点击“进入系统”，系统会用默认浏览器打开登录页面。
5. 如需创建桌面快捷方式，点击程序中的“创建桌面快捷方式”。

三、服务器地址
默认地址：
http://192.168.18.36:8090/

如果主机 IP 地址发生变化：
1. 在主机电脑运行“主机端-一键开启局域网访问”。
2. 主机工具会显示新的局域网地址。
3. 在客户端程序顶部输入新的地址。
4. 点击“测试连接”，成功后点击“保存设置”。

注意：
- 不要填写 localhost 或 127.0.0.1，这两个地址只代表当前电脑。
- 不要使用 https://，局域网默认使用 http://。
- 客户端不需要安装数据库，也不保存业务数据。

四、无法连接时
1. 在客户端电脑打开命令行，执行：
   ping 主机IP地址
2. 再执行：
   Test-NetConnection 主机IP地址 -Port 8090
3. 如果 TcpTestSucceeded 为 False，请检查主机防火墙或是否运行主机端工具。
4. 如果浏览器使用了代理，请将 192.168.*、10.*、172.16.* 加入代理例外。
5. 如果多台电脑互相 ping 不通，请检查路由器是否开启了“终端隔离/AP 隔离”。

五、多用户说明
所有客户端连接的是同一台主机的数据库，多人可以同时登录编辑。客户端电脑不要复制或共享主机的数据库文件。

六、连接超时诊断
1. 双击“局域网连接诊断.bat”。
2. 工具会自动检查客户端与主机网段、Ping 和 8090 端口。
3. 若“与主机网段一致：否”，说明两台电脑不在同一网络/网段。
4. 若 Ping 失败，重点检查路由器终端隔离、访客网络和 VPN。
5. 若 Ping 成功但端口失败，主机端重新运行“主机端-一键开启局域网访问”。
6. 若均成功但浏览器仍打不开，检查浏览器代理，确保局域网地址绕过代理。

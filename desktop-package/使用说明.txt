# 进销存系统 电脑局域网版

## 首次使用

1. 双击 `安装局域网防火墙.bat`，在 Windows 提示中选择“是”。
2. 双击 `启动进销存系统.bat`。
3. 浏览器会自动打开 `http://localhost:8090`。
4. 默认账号：`admin`，默认密码：`admin123`，登录后立即修改密码。
5. 其他电脑连接同一局域网后，双击 `查看局域网地址.bat` 获取本机地址，在浏览器访问：
   `http://本机IP:8090`

## 多用户

- 管理员登录后，在「系统 → 用户管理」创建不同员工账号并分配角色。
- 支持多人同时登录、录入和编辑。
- 数据库实体启用乐观锁；同一记录发生并发冲突时会提示，不会静默覆盖。

## 停止系统

双击 `停止进销存系统.bat`。

## 数据备份

双击 `备份数据.bat`，备份文件保存在 `backups` 目录。

建议每天营业结束后备份一次。

## 数据位置

- 数据库：`data/ivs.mv.db`
- 运行日志：`logs/`
- 备份：`backups/`

不要随意删除 `data` 目录。

## 系统要求

- Windows 10 / Windows 11 64 位
- 已内置 Java 运行环境，无需另外安装 Java
- 默认端口：8090
- 使用前请确保 8090 端口未被其他程序占用
